## 新增

- **第一次打开时有个引导**：登录、语音怎么出声、填直播间号，三步走一遍就能开播。每一步都能单独跳过，也能一键「全部跳过」—— 跳过的步骤不会改你已经配好的东西。以后想再看一遍，去「关于」页点「重新打开」。
- **能查更新了**：打开软件时去 GitHub 看一眼最新版本，有新版本会在顶栏出一个提示条，顺手给下载链接。整个过程只查一次，连不上就算了，不会反复重试；不想自动查可以在「关于」页关掉。也可以随时点「检查更新」手动查。
  - 只认**线上版本号更高**才算有新版本，所以从源码跑的时候不会莫名提示「有新版本」。
- **多了一套 Material 2 风格**：「外观」页新增「界面风格」，选 *Material 2* 就是方角、扁平、靠阴影分层的旧版安卓模样；选 *Material 3*（默认）还是现在的大圆角。**四个浮窗和 OBS 叠加层会一起换**，不用逐个重开。

## 修复

- **在设置里换主题、改浮窗参数，浮窗要重开一次才生效**：以前配置改完只落盘、没通知界面，浮窗就一直用老样子。现在改完当场变。
- **浮窗从来没跟随过主题色**：它一直用样式表里写死的深紫，你在主界面怎么调都不动它。现在跟主窗口同源，换种子色、切亮暗、切风格都同步。

## 说明

- 新手引导只对**全新安装**出现；已经在用的不打扰，想看得去关于页手动打开。
- 检查更新用的是 GitHub Releases，国内直连失败属于正常，失败时不会弹任何东西。
